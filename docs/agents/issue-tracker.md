# Local issue tracker

Track integration specs and tickets as Markdown files under root `.scratch/`.
Existing application tickets remain under `niribar/.scratch/` and `notify/.scratch/`.
Reference their paths explicitly; do not duplicate or renumber historical issues.
The current integration slice is shared provider contracts, the next foundation in
phase 6 of `docs/canopa-integration-proposal.md`, scoped in
`docs/adr/0006-shared-provider-contracts.md`. Previous workspace, configuration,
appearance, notification and asset slices are recorded in ADRs 0001–0005. Both
existing protocols remain supported; a versioned successor and a first portal
interface remain separate work.
