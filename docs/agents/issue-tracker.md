# Local issue tracker

Track integration specs and tickets as Markdown files under root `.scratch/`.
Existing application tickets remain under `niribar/.scratch/` and `notify/.scratch/`.
Reference their paths explicitly; do not duplicate or renumber historical issues.
The current integration slice is shared assets, the first part of phase 6 in
`docs/canopa-integration-proposal.md`, scoped in `docs/adr/0005-shared-assets.md`.
Previous workspace, configuration, appearance and notification slices are recorded
in ADRs 0001–0004. Provider convergence and a first portal interface remain separate
work after assets.
