# Local issue tracker

Track integration specs and tickets as Markdown files under root `.scratch/`.
Existing application tickets remain under `niribar/.scratch/` and `notify/.scratch/`.
Reference their paths explicitly; do not duplicate or renumber historical issues.
The current integration slice is provider convergence in phase 6 of
`docs/canopa-integration-proposal.md`, scoped in
`docs/adr/0007-unified-panel-protocol.md`. Built-in Wi-Fi and Center providers use
v5; explicit v1/v4 compatibility remains. Previous slices are recorded in ADRs
0001–0006. A first portal interface remains separate work.
