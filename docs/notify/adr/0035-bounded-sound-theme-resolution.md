# Bounded sound-theme resolution

Sound lookup belongs in one private module behind `SoundPresenter`, separate from playback and runtime mutation. Follow the Sound Theme 0.2 narrative's selected-theme/recursive-parent/freedesktop/unthemed precedence, using declared directory order and output profiles, ordered XDG roots, event-name fallback and locale fallback. An explicit `.disabled` result stops lookup and application-default fallback; cancellation, invalid metadata and exhausted lookup budgets also stop instead of guessing past a possible user override. Missing files alone permit fallback.

Use the first `index.theme` across roots; read it nonblocking as a bounded regular file and inspect only declared relative directories. Keep fixed `stereo`, `mono` and root probes for legacy unindexed installations, but remove recursive filesystem scanning. Read indexes anew per lookup so edits are visible without a lifetime path cache. Notify requests stereo event sounds, then profile-less sounds; inferring surround layouts from channel count or adding a profile setting is not part of this tranche. Files with `.flac`/`.mp3` remain local extensions after the standard `.oga`/`.ogg`/`.wav` order.

The fixed safety policy limits roots and visited themes to 32 each, index files to 64 KiB, declared directories to 64 and inherited names to 32 per index, with 4,096 traversal/candidate checks per lookup. Index parsing also caps groups and keys per group at 128. More than 32 eligible roots stops lookup rather than silently truncating priority. Names/locale components are basenames of at most 255 bytes; relative directory declarations are at most 1,024 bytes and cannot contain parent traversal. Invalid or oversized first indexes do not fall through to a lower-priority index. Checks cooperate with ADR 0034 cancellation. A requested name and application default can each perform a lookup; these bound application work, not filesystem response time. The four-job and file/PCM limits still apply.

Capture locale settings at presenter startup with `LC_ALL`, `LC_MESSAGES`, then `LANG` precedence. Try literal locale components and their codeset-free equivalents, dropping modifier and territory before `C` and unlocalized files. Unsafe/oversized locale components use `C`/unlocalized fallback. No process-global locale mutation is needed, and fixtures inject locale settings without changing the test runner's environment.

Retain the in-process Rodio backend under ADR 0025. The reviewed [libcanberra public interface](https://0pointer.de/lennart/projects/libcanberra/gtkdoc/libcanberra-canberra.html) owns playback rather than exposing standalone file resolution, so adopting it would replace the tested PCM/admission contract and add native integration. Its source endpoints could not be retrieved during this review; no comparative runtime-fixture or maintenance-status claim is made. The authoritative [lookup rules](https://specifications.freedesktop.org/sound-theme/0.2/sound_lookup.html), [index format](https://specifications.freedesktop.org/sound-theme/0.2/file_formats.html) and [directory/disable rules](https://specifications.freedesktop.org/sound-theme/0.2/directory_layout.html) guide Notify's own offline fixtures. The published lookup pseudocode conflicts with its prose on parent/default ordering; parent themes precede the global default here.
