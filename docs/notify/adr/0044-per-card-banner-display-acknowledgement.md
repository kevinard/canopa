# Per-card banner display acknowledgement

ADR 0028's display-based timeout must not wait for unrelated cards to fit. The runtime binds independently consumable acknowledgements to captured Banner Targets; the renderer reports each card when its full compact layout is inside the drawing viewport, so scrolling may start one card's timer without starting another's. Containment allows half a logical pixel at each edge because Iced rounds scroll translation; otherwise fractional bottom-card geometry can never qualify at maximum scroll. Counting a sliver of a clipped card as display would expire content before its controls were reachable; the body may still scroll within the bounded compact preview.

Acknowledgement is idempotent and releases consumed callbacks outside its lock. A frame owns its captured acknowledgement even if a newer projection arrives before dispatch; runtime registration and revision checks remain authoritative under ADR 0033. Synchronous presenters can still acknowledge a whole projection, and existing whole-presentation observers remain supported, but the Notification Runtime uses per-card targets. This processed-redraw milestone does not certify compositor presentation, physical output fit, occlusion or a card taller than its viewport; output-aware geometry and the supported-scale matrix remain separate acceptance work.
