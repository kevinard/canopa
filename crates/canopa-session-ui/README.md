input, authentication prompt presentation and scoped widget observation. Used by
Canopa Lock, Canopa Greeter and Canopa Polkit, with no PAM execution or Wayland surface roles.

session lifetime. See [session tools](../../docs/session-tools.md) and
[greeter setup](../../docs/greeter.md).
